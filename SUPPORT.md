# Поддержка

Инструменты в организации сделаны людьми из студии в рабочее время. Поддержка — по мере сил, без сроков.

- Не работает или непонятно, как поставить — issue в репозитории инструмента. Владелец и заместитель указаны в его README и в каталоге студии.
- Срочно, горит проект — напишите владельцу в рабочий чат и приложите ссылку на issue, чтобы ответ не потерялся.
- Вопрос не про конкретный инструмент — issue в `relatetest/hub`.
