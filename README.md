# .github

Файлы по умолчанию для всех репозиториев организации `relatetest`. GitHub показывает их в любом репозитории, где нет своих: шаблоны issues и PR, CONTRIBUTING, SECURITY. `profile/README.md` — публичная страница организации.

Репозиторий публичный, потому что GitHub берёт файлы по умолчанию только из публичного `.github`. Поэтому здесь нет ничего внутреннего: ни данных, ни описаний инструментов. Правила и каталог студии — в закрытом [relatetest/hub](https://github.com/relatetest/hub).
